# 小程序分类过滤条箭头展开设计

## 背景

供需市场页和供需搜索页当前在二级分类横滑区域右侧放置“全部分类”文字按钮。该按钮宽度较大、色块明显，与左侧分类按钮的视觉层级接近，导致过滤条显得拥挤，也压缩了可见分类数量。

本次优化将“全部分类”改为紧凑的单箭头入口，并让分类面板在过滤条下方原位展开，使入口状态、面板位置和用户操作保持连续。

## 目标

1. 降低“全部分类”入口的视觉重量，增加横滑分类的可见空间。
2. 通过向下、向上箭头明确表达分类面板的收起和展开状态。
3. 让分类面板靠近触发入口，减少从过滤条到页面底部抽屉的视觉跳跃。
4. 保持搜索页和供需市场页的分类筛选行为一致。
5. 不修改后端接口、分类数据结构、查询参数和现有资源加载逻辑。

## 不在本次范围

- 不调整一级类目标题栏和一级类目抽屉。
- 不修改搜索框、标签筛选、热门关键词和资源卡片。
- 不增加分类图标、分类运营配置或新的后端字段。
- 不重构分类数据加载和分组逻辑。

## 视觉设计

### 过滤条

二级分类横滑区域和箭头入口组合为一个完整的白色过滤控件：

- 外层高度保持 `80rpx`，使用白色背景、`1rpx` 细边框、`10rpx` 圆角和 `4rpx` 内边距，与现有搜索框和页面卡片保持一致。
- 左侧保留横向滚动的二级分类按钮。
- 右侧放置 `72rpx × 72rpx` 的方形箭头按钮，不再显示“全部分类”文字。
- 箭头按钮使用现有浅蓝辅助背景和主文字色，保持可点击性，但不与搜索按钮争夺主操作层级。
- 横滑分类继续使用现有选中态和未选状态，不在本次改动中重新定义分类按钮配色。

箭头只显示一个状态，不同时展示上下双箭头：

- 分类面板收起时，箭头向下。
- 分类面板展开时，箭头向上。

这样可以避免用户将上下双箭头误解为排序控件。

### 原位分类面板

分类面板紧贴过滤条下方展开：

- 使用三列网格展示当前一级类目下的全部二级分类。
- “全部”作为第一个选项，保持现有清空二级分类筛选的语义。
- 当前选项使用现有浅橙背景和加粗文字，其他选项使用白色或页面浅灰背景。
- 面板使用细边框、圆角和轻阴影，与过滤条形成同一层级的组合控件。
- 面板最大高度为 `360rpx`；分类数量超出可见区域时允许面板内部纵向滚动，避免遮挡大部分结果列表。
- 面板不增加独立标题和“关闭”按钮，减少重复信息；箭头本身承担展开和收起操作。

## 交互规则

1. 初始状态下分类面板收起，箭头向下。
2. 点击向下箭头后：
   - 分类面板在过滤条下方展开；
   - 箭头切换为向上；
   - 当前已选分类保持高亮。
3. 点击向上箭头后，面板收起，箭头恢复向下。
4. 在面板中选择分类后：
   - 复用现有 `selectType` 筛选逻辑；
   - 更新横滑区域的选中项；
   - 重新加载对应资源列表；
   - 分类面板自动收起；
   - 页面滚动和选中项定位行为保持现有逻辑。
5. 点击分类面板外区域时，面板收起，不改变当前筛选条件。
6. 切换一级类目时，二级分类继续按现有规则重置，并关闭已展开的分类面板。
7. 页面离开、返回或重新初始化时，分类面板默认保持收起，不持久化展开状态。

## 页面适配

本次设计同时应用于：

- `wxapp/pages/market/index.vue`
- `wxapp/pages/search/index.vue`

两个页面复用相同的类名、状态命名和交互规则，避免相同控件出现不同体验。搜索页现有标签筛选行继续显示在分类过滤条和原位分类面板之后。

小屏设备上仍保持三列分类网格。分类按钮高度统一为 `72rpx`，文案最多显示两行；超过两行时截断，不能撑破网格。

## 状态与实现边界

两个页面都将现有 `showTypeDrawer` 状态重命名为 `showTypePanel`，打开、关闭方法对应使用 `openTypePanel` 和 `closeTypePanel`，避免继续沿用底部抽屉语义。

现有底部分类抽屉模板和以下仅服务于底部抽屉的样式将被替换：

- `type-drawer-mask`
- `type-drawer-panel`
- `type-drawer-head`
- `type-drawer-title`
- `type-drawer-close`

一级类目抽屉仍保留现有底部抽屉交互，不能因样式清理受到影响。若一级类目和二级分类共用了部分选择按钮样式，只拆分二级分类面板所需样式，不进行无关重构。

## 可访问性与容错

- 箭头按钮保留足够的点击热区，不因移除文字而降低可操作性。
- 按钮需要有可识别的状态语义：收起时为“展开全部分类”，展开时为“收起全部分类”。
- 箭头旋转只作为状态反馈，不依赖动画完成操作；减少动态效果设置下仍能直接显示最终状态。
- 分类接口失败时继续沿用现有兜底分类和错误处理，不因面板改造阻断资源浏览。

## 验证标准

### 静态与交互测试

- 搜索页和供需市场页不再显示“全部分类”文字按钮。
- 两个页面都包含固定宽度的箭头按钮和原位分类面板。
- 箭头按钮能在收起、展开状态间切换。
- 选择任意二级分类后面板自动收起，并触发现有筛选加载逻辑。
- 选择“全部”后清空 `typeCode`，行为与当前实现一致。
- 点击面板外区域只关闭面板，不改变筛选条件。
- 切换一级类目会关闭二级分类面板。
