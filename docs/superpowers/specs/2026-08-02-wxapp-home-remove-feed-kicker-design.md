# 小程序首页移除内容区眉题设计

日期：2026-08-02

## 1. 目标

移除小程序首页内容发现区的“织里商机 · 持续更新”眉题，避免在“新入驻商家 / 近期供需”栏目标题前重复说明内容属性。

## 2. 改动范围

- 删除 `wxapp/pages/home/index.vue` 中渲染该眉题的 `<text class="home-feed-kicker">` 元素；
- 删除仅服务于该元素的 `.home-feed-kicker` 样式；
- 将 `wxapp/pages/home/index.test.mjs` 的源码断言调整为确认该文案不再出现。

## 3. 保持不变

- 当前栏目与另一栏目之间的切换、无障碍语义和数据加载逻辑；
- 内容区标题行、列表、查看更多入口及其间距规则；
- 首页的 Banner、搜索、快捷入口和其他内容模块；
- 接口、状态管理、依赖和页面路由。

## 4. 验收标准

1. 首页不再渲染“织里商机 · 持续更新”。
2. 内容区仍正常展示“新入驻商家”或“近期供需”，并可按原逻辑切换。
3. 首页源码测试通过，且未引入新的依赖或行为变更。
