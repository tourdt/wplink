# 供需详情操作弹窗图标宫格设计

## 背景与目标

供需详情页的访客“更多操作”弹窗和发布者“管理”弹窗当前使用横向文字按钮。动作数量较少，但按钮的视觉形态接近普通表单操作，用户需要逐字阅读才能识别收藏、分享、举报、刷新、置顶等功能。

本次将两个弹窗统一调整为“图标在上、文字在下”的轻量宫格。目标是提高动作辨识速度、扩大稳定的点击热区，并让访客操作与发布者管理保持一致的视觉语言。现有业务动作、权限判断、状态分支和跳转行为全部保持不变。

## 范围

### 包含

1. 访客点击底部“更多”后，收藏、分享给朋友、举报以轻量圆形图标和下方文字展示。
2. 发布者点击“管理”后，编辑、刷新、置顶、下架、再发类似、删除等当前可用动作使用相同布局。
3. 管理动作根据资源状态仍可显示一至三个，布局需要自动居中且保持均衡间距。
4. 收藏状态继续通过“收藏 / 取消收藏”文字表达；危险动作继续使用红色语义。
5. 更新供需详情页前端回归测试，覆盖弹窗结构、动作图标和原有行为。

### 不包含

1. 不修改底部联系栏、发布者底部操作栏或弹窗标题区结构。
2. 不增加、删除或重新排序任何业务动作。
3. 不修改收藏、分享、举报、刷新、置顶、下架、删除等业务逻辑。
4. 不修改登录校验、付费解锁、资源状态判断、接口或数据库。
5. 不引入第三方图标库。

## 视觉方案

采用已确认的“A · 轻量圆形”方案。

每个动作由一个完整按钮承载，按钮内部纵向排列：

```text
      线性图标
        动作文字
```

- 图标放在浅色圆形容器内，使用统一尺寸和线条粗细。
- 普通动作使用项目现有深蓝灰主色；圆形背景保持白色或极浅蓝灰，并用细边框和轻阴影建立点击感。
- 举报、删除、下架等危险动作使用克制的红色图标、边框和浅红背景，不使用大面积实色按钮。
- 动作文字位于图标下方，保持单行居中；较长的“分享给朋友”“再发类似”仍需完整显示。
- 不再以整块深色按钮区分 `primary` 动作，避免宫格中出现过重色块；业务优先级继续由动作顺序和危险色表达。

## 布局与交互

### 访客更多弹窗

固定展示三个动作，顺序保持：收藏或取消收藏、分享给朋友、举报。

三个按钮等宽排列，图标和文字垂直居中。按钮整体仍是点击热区，不能只让图标或文字可点击。分享按钮继续保留微信小程序 `open-type="share"`。

### 发布者管理弹窗

继续复用 `managementActions` 的状态计算结果，不改变动作集合：

- 草稿或驳回：编辑；
- 已下架：再发类似、删除；
- 已过期或已完成：再发类似；
- 已发布：刷新、置顶、下架；
- 自动检测等无动作状态：继续显示现有说明和空态，不渲染宫格。

宫格使用可自动居中的横向弹性布局。一个动作位于中间，两个动作均衡分布，三个动作等距排列；单个按钮设置稳定宽度上限，避免一个动作被拉伸为整行大卡片。

### 原有交互保留

- 点击遮罩关闭弹窗；点击弹窗内容不冒泡关闭。
- 点击动作后是否关闭弹窗，继续沿用各处理函数当前逻辑。
- 收藏成功后的文字状态、分享回调、举报页跳转、管理动作反馈保持不变。
- 弹窗底部继续适配安全区。

## 图标实现

在小程序静态资源目录增加本地线性 SVG 图标，覆盖收藏、分享、举报、编辑、刷新、置顶、下架、再发类似和删除。图标均为项目内静态资源，不依赖网络和第三方图标包。

`managementActions` 为每个动作补充对应的图标路径；模板在原有文字前增加图标节点。访客“更多操作”保留现有按钮事件与分享属性，仅调整按钮内部结构并指定图标资源。

图标是辅助识别，文字标签始终保留，避免仅依赖图形或颜色表达含义。

## 测试与验收标准

1. 访客“更多操作”中的三个动作均显示圆形图标和下方文字，顺序不变。
2. 发布者“管理”中的所有可用动作均带有正确图标；一、二、三个动作时均居中、间距均衡。
3. 普通动作使用统一主色，举报、删除、下架保持危险色，但没有大面积高饱和色块。
4. 收藏或取消收藏、微信分享、举报跳转及全部管理动作仍调用原处理函数。
5. 分享按钮保留 `open-type="share"`，弹窗遮罩、关闭按钮和安全区行为不变。
6. 无管理动作时继续显示现有状态说明和“暂无可操作功能”。
7. 资源详情页单元测试、页面流程校验和微信小程序构建通过。
