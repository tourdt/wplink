# 供需详情友情提示位置调整设计

## 背景

当前供需详情中的“友情提示”位于“同类推荐”之后。提示内容用于提醒用户在联系供需方前确认实物、价格、数量和交付方式，但现有位置与联系商家、交易确认的行为距离较远，容易在用户开始浏览其他供需后被忽略。

## 目标

让交易提醒紧邻商家资料与后续联系行为，同时保持供需主体信息的连续阅读顺序。

## 页面顺序

详情主体调整为：

1. 供需摘要
2. 详细参数
3. 地址（存在时）
4. 商家资料入口（满足现有显示条件时）
5. 友情提示
6. 同类推荐（存在时）

商家资料入口不显示时，友情提示自然承接在地址或详细参数之后，不新增占位区域。

## 改动边界

- 仅移动现有 `trust-card` 模板位置。
- 不修改友情提示的文案、样式或显示条件。
- 不修改商家资料入口和同类推荐的显示规则。
- 不调整详情数据请求、接口、状态或底部操作栏。

## 验收标准

- 模板中 `merchant-card` 位于 `trust-card` 之前。
- `trust-card` 位于 `related-section` 之前。
- 商家资料或同类推荐隐藏时，友情提示仍正常显示。
- 供需详情相关测试、小程序全量检查及微信小程序构建通过。
