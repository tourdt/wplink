# 供需详情紧凑说明与参数布局设计

## 目标

将类型、供需方向和发布标签与真实描述收敛为一个首屏信息块，去除“补充说明”标题，减少重复卡片。参数保持双列为主，仅为地址、备注/说明、交期/要求或明显长文本保留整行阅读空间。

## 范围

1. `detail-summary-card` 同时承载方向、类型、发布标签和非空描述；不再使用独立 `description-card` 或“补充说明”标题。
2. 描述为空时，摘要卡仅展示方向、类型和标签。
3. 参数整行规则收窄为：标签包含地址、备注、说明、交期、时效、要求，或值含换行、长度超过 20 个字符。
4. 地址仍由独立地址区块展示，参数、图片、商家、推荐、联系、管理和接口均不调整。

## 验收标准

1. 页面不再出现“补充说明”标题或 `description-card`。
2. 描述存在时紧跟在类型/标签之后展示，描述为空不留占位。
3. “服务范围”等短文本恢复双列；交期要求、备注说明与超过 20 字的值仍独占整行。
