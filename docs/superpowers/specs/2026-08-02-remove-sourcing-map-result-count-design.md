# 拿货档口移除结果数量文案设计

## 目标

移除拿货档口页面搜索框下方的“xx 个档口”数量文案，减少无必要的信息占位，让筛选条件更靠近搜索区域。

## 改动范围

- 删除 `wxapp/pages/sourcing-map/index.vue` 中仅用于展示数量的 `directory-summary` 和 `result-count` 节点。
- 删除上述节点对应的专用样式。
- 筛选标签自然上移，并继续使用现有 `16rpx` 顶部间距。
- 保留 `total` 状态及接口返回值处理，因为列表分页和“是否还有更多”判断仍依赖它。

## 不改动内容

- 不改变搜索、筛选、分页、加载状态和空状态逻辑。
- 不改变接口请求或返回数据结构。
- 不新增替代数量文案或空白占位。

## 验证标准

- 页面模板不再包含“个档口”、`directory-summary` 或 `result-count`。
- 页面仍保留基于 `total` 的分页判断。
- 拿货档口页面测试通过，小程序完整检查与构建通过。
