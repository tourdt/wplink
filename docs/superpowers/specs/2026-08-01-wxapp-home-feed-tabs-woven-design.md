# 小程序首页织带式内容栏目设计

日期：2026-08-01

## 1. 背景与目标

首页“新入驻商家 / 近期供需”当前采用左对齐文字标签和底部细线。该方案足够轻量，但更接近通用选项卡，缺少首页栏目应有的识别度，也没有体现织里童装产业带的产品气质。

本设计以“服装织带标签”为视觉原型，用一个深色栏目签表达当前内容类型。目标是在不增加卡片嵌套、不改变数据逻辑的前提下，让内容区更精致、更有首页栏目感。

本设计取代 `2026-08-01-wxapp-home-feed-tabs-visual-polish-design.md` 中的纯文字下划线方案。

## 2. 已确认方案

内容区顶部由栏目眉题和织带式栏目签组成：

```text
织里商机 · 持续更新

┌──────────────────▶   近期供需
│ 新入驻商家
└──────────────────▶

当前栏目对应的内容列表
```

- 栏目眉题固定为“织里商机 · 持续更新”，使用弱化文字色；
- 当前栏目使用深海军蓝底、白色文字、左侧橙色竖向缝线和右侧小切角；
- 未选中栏目保持透明背景和弱化文字色；
- 标签组只保留上下细分隔线，不使用圆角外框、胶囊底或阴影；
- 当前标签切换时只改变视觉状态，不改变两个标签的位置和尺寸。

## 3. 视觉规格

### 3.1 栏目眉题

- 文案：`织里商机 · 持续更新`；
- 字号：`22rpx`；
- 字重：`600`；
- 颜色：`$wplink-muted`；
- 字间距：`1rpx`；
- 与标签组的间距：`12rpx`。

### 3.2 标签组

- 使用横向 `flex` 排列；
- 标签之间保留 `18rpx` 间距，为右侧切角留出空间；
- 顶部和底部均使用 `1rpx solid $wplink-line` 分隔线；
- 标签组不设置背景、圆角和阴影；
- 标签组与内容列表的间距保持 `20rpx`。

### 3.3 标签

- 每个标签最小高度为 `88rpx`；
- 两个标签都使用固定的 `padding: 0 28rpx`，选中状态不得修改 padding、字号或字重；
- 字号：`27rpx`；
- 字重：`700`；
- 未选中文字颜色：`$wplink-muted`；
- 当前标签背景：`$wplink-primary`（`#061625`）；
- 当前标签文字：`#ffffff`；
- 左侧缝线宽 `4rpx`、高 `32rpx`，颜色为 `$wplink-accent`（`#c23a00`）；
- 右侧切角宽 `14rpx`，使用 CSS 边框三角形形成，不使用 `clip-path` 或图片资源；
- 按下态仅将透明度调整为 `0.82`，不增加缩放、位移或循环动画。

两个标签始终同时占据自己的固有位置。选中项切换时，深色织带从一个标签切换到另一个标签，但标签文字和后续列表不得横向跳动。

## 4. 交互与状态

- 两类内容都有数据时显示栏目眉题和两个可切换标签；
- 使用现有 `activeHomeFeedTab` 表达选中项；
- 点击标签继续调用 `selectHomeFeedTab('merchants' | 'resources')`；
- 切换只更新本地状态，不重新请求接口；
- 标签容器继续使用 `role="tablist"` 和 `aria-label="首页内容"`；
- 标签按钮继续使用 `role="tab"` 和动态 `aria-selected`。

只有一类内容可用时：

- 继续显示栏目眉题；
- 不显示可切换标签组；
- 使用同样的深色织带样式静态展示唯一栏目名称；
- 静态栏目签使用 `view`，不提供点击态、`role="tab"` 或伪装的切换入口。

两类内容均不可用时，继续隐藏整个首页内容区。

## 5. 组件与数据边界

改动继续集中在 `wxapp/pages/home/index.vue`：

1. 在内容区内增加栏目眉题；
2. 将现有 `.home-feed-tabs` 和 `.home-feed-tab` 调整为织带式样式；
3. 将单内容标题调整为静态织带样式；
4. 保留 `activeHomeFeedTab`、`selectHomeFeedTab()`、`homeFeedState` 与 `v-if / v-else` 内容渲染。

不新增组件，不增加图片资源，不修改接口、状态模块、商家卡片或供需卡片。

## 6. 异常与降级

- 新入驻商家为空或加载失败：继续展示近期供需的静态织带栏目签；
- 近期供需最终为空：继续展示新入驻商家的静态织带栏目签；
- 两类数据均为空：不渲染栏目眉题、标签或列表容器；
- 资源接口兜底和商家接口静默失败逻辑保持不变；
- 个别列表字段缺失继续由现有卡片组件处理，不在栏目头增加错误或空态分支。

## 7. 测试与验收

### 7.1 自动化验证

1. 两类内容可用时，模板包含栏目眉题和双标签语义；
2. 两个标签继续调用原有切换函数并暴露正确的 `aria-selected`；
3. 选中和未选中状态使用相同的 padding、字号和字重；
4. 标签保留 `min-height: 88rpx`；
5. 当前标签包含深色背景、白色文字、橙色缝线和 `14rpx` 右侧切角；
6. 标签组不包含圆角、胶囊背景或阴影；
7. 单内容状态使用静态栏目签，不渲染不可操作的标签按钮；
8. 运行首页定向测试和 `npm run check`。

### 7.2 视觉验收

1. 在 `320px`、`375px` 和 `430px` 视口宽度下，两个标签保持单行，切角不覆盖相邻标签；
2. 在两个栏目之间切换时，标签文字和首张列表卡片不横向位移；
3. 深色织带是栏目头唯一强视觉元素，不与下方卡片争夺层级；
4. 当前栏目与未选中栏目能在一眼内区分；
5. 单内容状态与双标签状态保持同一套栏目语言；
6. 微信开发者工具中检查深色背景、橙色缝线和小切角无锯齿或裁切。

## 8. 不在本次范围

- 不修改首页接口、请求时机、排序、数量和降级策略；
- 不调整商家与供需列表卡片；
- 不增加数字徽标、自动轮播、滑动切换或音效；
- 不增加新的图片、字体或第三方依赖；
- 不改造其他页面的标签控件；
- 不调整首页 Banner、快捷入口和搜索区。
