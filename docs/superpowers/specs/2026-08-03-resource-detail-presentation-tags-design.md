# 供需详情展示标签去重设计

## 目标

避免详情首行类型/分类与第二行标签重复。后端在展示模型中提供已过滤的 `presentation.tags`，前端仅负责渲染。

## 规则

1. 过滤空标签并保持原始业务标签顺序。
2. 去除重复标签。
3. 标签与 `typeName` 或 `category` 完全相同则隐藏。
4. 标签被 `typeName` 或 `category` 完整包含则隐藏。
5. 不使用模糊语义匹配，避免误删有效特征标签。

## 接口与前端

- `presentation` 新增 `tags []string`。
- 详情页不再直接读取资源原始 `tags`。
- 类型、标签、描述仍位于同一紧凑摘要卡。

## 验收

类型“工厂直供”、分类“童装”、标签“工厂直供、童装、现货、可混批”时，接口只返回并展示“现货、可混批”。
