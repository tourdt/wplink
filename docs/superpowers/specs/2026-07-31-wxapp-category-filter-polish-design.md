# 小程序分类过滤栏视觉精修设计

## 背景

供需市场页和供需搜索页已经完成“单箭头入口 + 原位展开分类面板”的交互改造，但当前样式仍存在三处视觉问题：

1. 过滤栏外框、分类按钮和箭头色块同时强调，控件内部层级不够集中。
2. 浅橙分类选中态与浅蓝箭头背景同时出现，视觉焦点分散，箭头看起来像独立功能按钮。
3. 展开面板只有分类网格，缺少明确的内容说明和当前状态反馈；边框、阴影与过滤栏叠加后略显厚重。

本次采用用户确认的 **A1「深色锚点」** 方案，在不改变现有筛选逻辑和面板结构的前提下，统一过滤栏与展开面板的视觉语言。

## 与前序规格的关系

本规格是对《小程序分类过滤条箭头展开设计》的视觉增量修订。前序规格中的原位展开、三列网格、最大高度、关闭规则和页面适配继续有效；其中“横滑分类继续使用现有浅橙选中态”“箭头使用浅蓝常驻背景”“面板不增加独立标题”三项由本规格替代。

## 设计目标

1. 让当前选中分类成为过滤栏中唯一明确的视觉锚点。
2. 弱化箭头入口的色块感，使其回归展开、收起控制角色。
3. 增强展开面板的标题层级、当前状态反馈和分类选中反馈。
4. 保持页面整体克制、专业、清晰，与搜索框和资源卡片的视觉风格协调。
5. 同步应用于供需市场页和供需搜索页，避免同一控件产生样式差异。

## 不在本次范围

- 不改变分类面板的展开、收起和选择逻辑。
- 不修改分类接口、分类数据、查询参数和资源加载逻辑。
- 不调整一级类目标题栏、一级类目抽屉、搜索框、标签筛选和资源卡片。
- 不新增图标资源、图片资源或后端配置。
- 不改变三列分类网格与 `360rpx` 最大滚动高度。

## 视觉设计

### 过滤栏整体

过滤栏继续作为一个完整的白色组合控件，保留现有高度和布局：

- 外层保持白色背景、`1rpx` 细边框、`10rpx` 至 `12rpx` 圆角和 `4rpx` 内边距。
- 阴影仅保留极弱的贴地效果，避免与展开面板阴影叠加后显得厚重。
- 左侧横向分类区和右侧箭头区仍保持现有空间分配，不改变分类可见数量和点击热区。
- 未选中的横滑分类使用透明背景和中性文字色，不再通过额外色块抢占注意力。

### 当前分类选中态

当前分类是整个控件的主要视觉锚点：

- 使用现有深色主色背景和白色文字。
- 字重适度提升，圆角与过滤栏内圆角保持一致。
- 不再使用浅橙背景作为主要选中态，避免与其他提示性状态混淆。
- “全部”和普通二级分类使用同一套选中规则，切换时只移动视觉锚点，不改变控件尺寸。

### 箭头入口

箭头仅表达面板状态，不再作为独立强调按钮：

- 移除现有浅蓝整块背景，改为透明背景。
- 箭头区左侧增加一条极浅分隔线，说明其与横滑分类属于同一组合控件。
- 点击热区保持 `72rpx × 72rpx`，不因视觉弱化而降低可操作性。
- 收起时箭头向下，展开时箭头向上；沿用现有状态语义与无障碍标签。
- 按压态可使用极浅灰或浅蓝反馈，但常态不保留色块。

### 展开面板容器

展开面板与过滤栏保持紧密连接，同时形成清楚的第二层内容区域：

- 与过滤栏间距保持约 `8rpx` 至 `12rpx`，避免粘连，也不产生明显断层。
- 使用白色背景、`1rpx` 中性细边框和 `12rpx` 圆角。
- 阴影调整为更轻、更集中、透明度更低的下投影；面板边界主要依靠边框而非重阴影表达。
- 保留 `360rpx` 最大高度和内部纵向滚动。
- 面板内边距统一，标题区、分类网格和容器边缘形成稳定的对齐关系。

### 面板标题与当前状态

在分类网格上方增加一行轻量标题区：

- 左侧显示“选择分类”，使用小号加粗主文字，说明当前面板用途。
- 右侧显示“当前：{分类名称}”，使用更小的弱化文字。
- 当前选择为“全部”时显示“当前：全部”；选择其他分类时展示对应分类名称。
- 标题区只提供信息反馈，不增加关闭按钮；用户仍通过向上箭头或选择分类关闭面板。
- 当前分类名称过长时使用单行省略，不能挤压左侧标题。

### 面板分类网格

分类选项继续使用三列网格，但减少大面积浅色块造成的拥挤感：

- 未选项使用极浅灰背景或透明细边框，文字采用中性深灰。
- 选中项使用深色主色背景和白色文字，与过滤栏选中态一致。
- 选中项右上角增加轻量对勾状态标识，强化“已选择”而非普通按钮的语义。
- 分类项高度、圆角和列间距保持一致；短文案与长文案都在视觉上居中。
- 文案最多显示两行，超过时截断，不改变网格行高。

## 交互与状态

本次只精修样式和状态展示，沿用现有交互：

1. 初始状态下分类面板收起，箭头向下。
2. 点击箭头后面板原位展开，箭头向上。
3. 展开时标题区显示当前分类名称，网格中对应分类使用深色选中态和对勾。
4. 在面板中选择分类后，筛选条件更新，横滑选中态同步，面板自动收起。
5. 点击面板外区域、切换一级类目或离开页面时，继续按现有逻辑收起面板。
6. 分类接口失败或使用兜底分类时，标题与网格仍根据当前本地状态正常显示。

## 页面适配

本次样式同时应用于：

- `wxapp/pages/market/index.vue`
- `wxapp/pages/search/index.vue`

两个页面使用一致的视觉参数、标题文案、选中态和对勾样式。搜索页位于分类面板之后的标签筛选区域保持原样。

## 实现约束

- 优先复用项目已有颜色变量；若现有变量无法表达极浅边框、按压背景或阴影，可在页面局部使用一致的颜色值，不新增无意义的全局变量。
- 对勾优先使用 CSS 绘制，避免新增图片请求和资源维护成本。
- 当前分类显示文本应通过已有 `selectedTypeLabel` 或等价计算值获得，不复制分类查找逻辑。
- 两个页面的模板和样式改动应保持结构一致，避免只在单页修复视觉问题。
- 不借本次样式精修重构筛选数据流或无关页面结构。

## 验证标准

### 视觉与状态验证

- 过滤栏中只有当前分类使用深色背景，未选分类保持轻量。
- 箭头常态无浅蓝整块背景，左侧具有轻量分隔边界。
- 展开面板显示“选择分类”和正确的当前分类名称。
- 横滑分类选中态与面板分类选中态使用同一深色视觉语言。
- 面板选中项显示对勾，未选项不显示。
- 展开面板边框、圆角、间距和阴影清晰但不过重。
- 小屏设备下三列网格不溢出，长分类名称不撑高分类项。

### 交互与回归验证

- 箭头展开、收起逻辑保持不变。
- 选择分类后面板自动收起并正常刷新资源列表。
- 点击面板外区域和切换一级类目仍能关闭面板。
- 供需市场页和供需搜索页的分类样式与行为一致。
- `wxapp/pages/market/index.test.mjs` 通过。
- `wxapp/pages/search/index.test.mjs` 通过。
- `wxapp/scripts/validate-flows.test.mjs` 通过。
- 小程序现有检查和构建命令通过。
