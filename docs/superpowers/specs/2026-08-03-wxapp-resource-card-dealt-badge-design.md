# 供需列表已成交角标设计

## 目标

让用户在首页和供需市场浏览列表时，能够快速识别已成交资源；移除会干扰文字阅读的整卡印章水印。

## 方案

仅调整共用组件 `wxapp/components/ResourceFeedCard.vue`：

- 已成交资源在封面右上角显示一个简洁的“已成交”角标。
- 角标使用较醒目的深灰蓝底色与白色文字，并适度增加高度、内边距和字号，确保列表快速扫读时可见。
- 移除整卡 `feed-completed-stamp` 印章及其样式和层级规则。
- 类型角标在已成交时收窄至剩余可用宽度，避免与右上角状态角标重叠；未成交时保留完整可用宽度。
- 不修改 `dealtAt` 的状态来源、接口、页面调用、卡片点击或资源生命周期规则。

## 验收标准

1. `dealtAt` 有值时，首页与供需市场列表卡片仅显示封面右上角“已成交”角标。
2. `dealtAt` 无值时不显示该角标；不显示任何整卡印章水印。
3. 类型角标与已成交角标不重叠，类型长文案仍能省略显示。
4. 卡片点击行为不变，组件测试和小程序完整检查通过。
