# 小程序首页内容栏目标题式切换设计

日期：2026-08-01

## 1. 背景与业务判断

首页从上到下依次承担搜索、品牌与运营曝光、场景快捷入口、内容发现四类任务。“新入驻商家 / 近期供需”位于快捷入口之后，属于首页内容发现区，不是页面级主导航。

两类内容在业务上并列，但作用并不完全对称：

- “新入驻商家”是平台给予新商家的扶持曝光位，最多展示 6 家，并在有数据时默认优先；
- “近期供需”是持续更新的高频市场内容，可包含运营推荐卡和公开资源兜底；
- 切换只改变本地可见内容，不重新请求数据；
- 只有一类内容可用时，不应显示伪切换入口；两类都为空时隐藏整个内容区。

传统等宽 Tab 会强化“控件”本身，织带式选中块又会与 Banner、快捷入口和内容卡片争夺视觉注意力。首页此处更需要告诉用户“正在看什么”，其次才是提示“还可以看什么”。

因此本设计采用“栏目标题 + 频道入口”的非对称切换方式。本设计取代 `2026-08-01-wxapp-home-feed-tabs-woven-design.md`。

## 2. 已确认方向

双内容状态使用以下结构：

```text
织里商机 · 持续更新

┃ 新入驻商家                         近期供需 →
──────────────────────────────────────

当前栏目内容列表
```

切换后：

```text
织里商机 · 持续更新

┃ 近期供需                         新入驻商家 →
──────────────────────────────────────

当前栏目内容列表
```

核心规则：

- 当前栏目始终位于左侧，使用大号标题表达；
- 另一个栏目始终位于右侧，使用弱化文字和右箭头表达切换入口；
- 用户已确认接受切换后两个栏目名称交换位置；
- 不使用胶囊、卡片底、实色大色块、织带切角、阴影或滑块；
- 视觉焦点落在当前内容标题，不落在切换控件的外形上。

这是本设计唯一具有辨识度的视觉动作：用“当前栏目回到标题位”的换位关系强化内容优先。其他部分保持克制。

## 3. 视觉规格

### 3.1 栏目眉题

- 文案固定为 `织里商机 · 持续更新`；
- 字号 `22rpx`；
- 字重 `600`；
- 字间距 `1rpx`；
- 颜色 `$wplink-muted`；
- 与栏目标题行间距 `8rpx`。

眉题只说明内容区属性和更新状态，不承担切换交互。

### 3.2 栏目标题行

- 使用横向 `flex`；
- 两端对齐，当前标题在左，另一频道入口在右；
- 最小高度 `88rpx`，保证两个可点击区域满足触控高度；
- 底部使用 `1rpx solid $wplink-line`；
- 与首个内容项间距 `20rpx`；
- 无背景、无圆角、无外描边、无阴影。

标题行内两个标签名称允许在切换时换位，但标题行宽度、底部分隔线和内容列表起点保持不变，不得造成列表横向或纵向跳动。

### 3.3 当前栏目标题

- 字号 `32rpx`；
- 字重 `800`；
- 行高 `1.2`；
- 颜色 `$wplink-primary`；
- 左侧内边距 `14rpx`；
- 左侧标记宽 `4rpx`、高 `32rpx`，颜色 `$wplink-accent`；
- 不使用背景、下划线、切角和阴影。

当前标题本身继续是可点击的 Tab，但重复点击只维持当前状态，不触发请求或额外反馈。

### 3.4 另一频道入口

- 字号 `25rpx`；
- 字重 `700`；
- 颜色 `$wplink-muted`；
- 文案为另一栏目名称，右侧附加 `→`；
- 名称与箭头间距 `8rpx`；
- 不使用按钮底、描边或胶囊外形；
- 按下态仅设置 `opacity: 0.72`，不使用缩放、位移或动画。

右箭头只表示同级频道切换，不表示进入新页面，因此切换后仍停留在首页当前滚动位置。

## 4. 交互与语义

### 4.1 双内容状态

- 保留 `role="tablist"` 和 `aria-label="首页内容"`；
- 当前栏目与另一栏目都使用 `role="tab"`；
- 当前栏目使用 `aria-selected="true"`，另一栏目使用 `aria-selected="false"`；
- 点击仍调用 `selectHomeFeedTab('merchants' | 'resources')`；
- 只更新 `activeHomeFeedTab`，不重新请求接口；
- 当前栏目在左侧、另一栏目在右侧，切换时动态交换文案和视觉角色。

视觉顺序与可访问语义保持一致：模板先输出当前 Tab，再输出另一 Tab，避免视觉顺序与焦点顺序不一致。

### 4.2 单内容状态

- 保留栏目眉题；
- 左侧使用与当前栏目标题一致的静态标题；
- 不显示右侧频道入口和箭头；
- 使用 `view`，不提供 `role="tab"`、`aria-selected` 或点击事件；
- 标题行仍保留底部分隔线和相同的内容间距。

### 4.3 空内容状态

- 两类内容均不可用时，继续隐藏整个内容区；
- 不单独展示栏目眉题、标题行或空态占位。

## 5. 数据和组件边界

改动继续集中在 `wxapp/pages/home/index.vue` 及其现有测试：

1. 将织带式双标签替换为动态的“当前栏目标题 + 另一频道入口”；
2. 将单内容织带签替换为静态栏目标题；
3. 删除织带背景、缝线切角和相关伪元素样式；
4. 保留栏目眉题、底部分隔线、现有状态计算和内容渲染。

以下部分保持不变：

- `homeFeedState` 的有无内容、默认栏目和降级判断；
- `activeHomeFeedTab` 与 `selectHomeFeedTab()`；
- 商家和供需接口、并行加载、失败处理与公开资源兜底；
- 商家数量上限、供需排序和运营推荐卡；
- 商家卡片、供需卡片、“查看更多”入口和所有跳转；
- Banner、搜索区、快捷入口和首页其他间距。

不新增组件、图片、字体、依赖、数字徽标、滑动手势或自动切换。

## 6. 异常与降级

- 新入驻商家加载失败或为空：展示“近期供需”静态栏目标题；
- 供需精选接口为空：继续使用现有公开资源兜底；
- 供需最终为空：展示“新入驻商家”静态栏目标题；
- 两类数据均为空：隐藏整个内容区；
- 个别卡片字段缺失：继续由现有卡片组件处理；
- 不在栏目标题中展示错误、重试或数量状态。

## 7. 测试与验收

### 7.1 自动化验证

沿用仓库现有首页源码断言方式完成 TDD，不引入新的组件渲染测试基础设施。

需验证：

1. 双内容状态继续包含 `tablist`、两个 `tab`、动态 `aria-selected` 和原切换函数；
2. 模板先输出当前栏目，再输出另一栏目，两个名称在状态切换后交换视觉角色；
3. 当前标题为 `32rpx / 800`，包含 `4rpx × 32rpx` 强调色左标记；
4. 另一频道入口为 `25rpx / 700`、弱化色和右箭头；
5. 标题行保留 `88rpx` 最小触控高度、底部分隔线和 `20rpx` 内容间距；
6. 不出现织带背景、右侧三角、胶囊、阴影、缩放、位移或切换动画；
7. 单内容状态使用静态标题，不包含 Tab 语义或点击事件；
8. 原数据、列表、请求和跳转逻辑未修改；
9. 首页定向测试和 `npm run check` 全部通过。

全量校验只允许仓库既有 Node.js ExperimentalWarning、Dart Sass 弃用提示和 uni-app 版本提示，不得新增其他警告。

### 7.2 视觉验收

1. 在 `320px`、`375px`、`430px` 视口下，两侧栏目名称保持单行且不重叠；
2. 切换前后当前栏目始终在左侧，另一栏目始终在右侧；
3. 名称换位不会引起首张列表卡片或内容容器位置跳动；
4. 当前栏目一眼可辨，但标题行的视觉重量低于 Banner 和快捷入口；
5. 右侧入口可理解为切换，而不是跳转到新页面；
6. 单内容状态没有残留箭头、空白按钮或伪交互区域；
7. 微信开发者工具中检查左侧标记、字体基线和底部分隔线无裁切。

## 8. 不在本次范围

- 不修改接口、请求时机、排序、数量或默认栏目；
- 不增加数量、红点、`NEW`、更新时间或轮播；
- 不调整列表卡片、更多按钮或空态；
- 不增加滑动切换和动效；
- 不改造其他页面的 Tab；
- 不调整首页其他模块。
