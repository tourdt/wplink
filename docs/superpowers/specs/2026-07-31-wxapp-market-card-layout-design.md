# 小程序供需市场列表卡片精简设计

## 背景

供需市场列表当前同时展示供需方向、业务类型、标题、品类与数量、价格或预算、地区、资源标签、商户和更新时间，正文行数较多，用户在连续浏览时难以快速聚焦交易条件。

当前业务主要服务织里地区，列表继续展示“织里”不能提供有效决策信息，反而会重复强调默认服务区域。用户已经确认采用 **C1「类型文案 + 供需色彩」** 方案：不再单独显示“供应 / 需求”，通过业务类型文案和角标颜色表达方向，并将价格或预算与数量提升到主要决策层。

## 设计目标

1. 降低供需市场列表单卡高度和正文行数，提升每屏可浏览的信息量。
2. 将标题、数量、价格或预算作为列表中的主要决策信息。
3. 去除“供应 / 需求”与具体业务类型之间的重复语义。
4. 移除地区和资源标签，避免弱相关信息分散注意力。
5. 保留业务类型、商户、更新时间和完成状态，确保用户仍能判断资源性质、来源和时效。
6. 将改动限制在供需市场页，避免影响首页、搜索、收藏和专题等复用同一卡片组件的页面。

## 不在本次范围

- 不修改资源接口、字段结构、分页、排序、曝光统计和详情跳转逻辑。
- 不改变供需市场的分类过滤栏、搜索入口、空状态和加载更多逻辑。
- 不同步修改搜索页、首页、收藏页、专题页或通用资源列表的卡片布局。
- 不调整资源详情页的信息展示。
- 不新增图片、图标或后端配置。
- 不改变业务类型与供需方向的既有数据映射。

## 信息层级

供需市场卡片统一收敛为“图片 + 三行正文”结构。

### 图片区域

- 图片尺寸由当前 `168rpx × 168rpx` 缩小为约 `152rpx × 152rpx`。
- 保持正方形、等比裁切、圆角和默认占位图逻辑。
- 图片左上角展示业务类型角标，例如“尾货批发”“工厂直批”“求购尾货”“招加工厂”。
- 不再单独展示“供应”或“需求”文案。
- 供应卡片的类型角标使用深色背景和白色文字。
- 需求卡片的类型角标使用橙色背景和白色文字。
- 类型名称过长时单行省略，不能撑大图片或遮挡过多主体内容。
- 已完成资源在图片右上角展示灰色“已完成”角标，与业务类型角标分居两侧。

### 正文第一行：标题

- 标题作为正文第一行，使用深色加粗文字。
- 单行显示，超出宽度时省略。
- 供应和需求卡片使用一致的字号、行高和截断规则。
- 标题缺失时沿用现有供应或需求兜底文案。

### 正文第二行：数量与价格

- 左侧显示数量信息，例如“现货 3000 件”或“需求 5000 件”。
- 右侧显示价格或预算，继续使用项目警示色和较高字重。
- 价格或预算是该行的主要视觉锚点；数量使用深色或中性深灰，保持可读但不与价格竞争。
- 业务品类不再与数量组成摘要，因为业务类型已经展示在图片角标上。
- 只有数量时保留数量并让右侧为空；只有价格或预算时仅展示价格或预算。
- 数量与价格或预算均缺失时，显示弱化的“交易信息待完善”，保持卡片结构稳定。
- 长价格文案使用单行省略，不能挤压图片或导致卡片横向溢出。

### 正文第三行：商户与更新时间

- 左侧显示商户名称，右侧显示现有格式化后的更新时间。
- 两者使用弱化文字色和较小字号，不抢占主要交易信息。
- 商户名称过长时单行省略，更新时间保持完整。
- 商户缺失时沿用现有“商家待确认”或“采购方待确认”兜底文案。

## 删除与迁移的信息

供需市场专用卡片中不再显示以下内容：

- 独立的“供应 / 需求”方向角标。
- 卡片正文中的业务类型角标。
- `district` 地区文本，包括“织里”。
- `category` 品类摘要。
- 最多三个资源标签。

上述信息没有从数据模型中删除，也不影响其他页面和详情页；本次只改变供需市场列表的展示层级。

## 卡片容器与间距

- 保持白色卡片、轻量阴影和现有列表间距，不改变页面整体视觉语言。
- 卡片内边距由当前 `24rpx` 适度收紧至约 `20rpx`。
- 图片与正文之间保持约 `12rpx` 间距。
- 正文三行在图片高度内垂直均匀分布，不能出现内容超出卡片或底部留白明显失衡。
- 供应卡片继续使用中性边界；需求卡片可保留现有极浅橙色边框，用于强化方向但不能与橙色类型角标竞争。
- 卡片整体点击区域和详情跳转行为保持不变。

## 组件作用范围

`ResourceCard` 当前还被首页、收藏、专题、搜索和通用列表复用，`DemandCard` 也被搜索页复用，因此不能直接全局替换默认结构。

实现时为两个组件增加一致的市场专用变体：

- `ResourceCard` 扩展现有 `variant` 规则，支持 `variant="market"`。
- `DemandCard` 增加同名 `variant` 属性并支持 `variant="market"`。
- `wxapp/pages/market/index.vue` 在渲染两种卡片时显式传入 `variant="market"`。
- 未传入 `market` 变体时继续使用现有模板、样式和信息结构。

市场专用结构应尽量复用已有的封面、业务类型、商户、更新时间和完成状态计算逻辑，不复制资源字段解析规则。

## 状态与异常处理

### 业务类型缺失

- 类型解析继续使用现有 `resourceTypeLabel` 逻辑。
- 若业务类型为空，不显示图片左上角标，不临时回退为“供应 / 需求”，避免违背去除重复方向文案的设计。
- 卡片标题、数量、价格、商户和更新时间仍按正常结构展示。

### 已完成状态

- `dealtAt` 存在时显示图片右上角“已完成”角标。
- 已完成状态不改变卡片点击行为。
- 两个角标同时存在时分别固定在图片左右两侧；文案过长时优先保证“已完成”完整，业务类型角标缩短并省略。

### 图片缺失

- 沿用现有默认封面图，不新增空图片状态。
- 类型和完成状态角标仍可叠加在默认封面上。

### 字段缺失

- 标题和商户沿用现有兜底文案。
- 数量、价格或预算按实际存在情况组合，不输出多余分隔符。
- 数量和价格或预算都为空时使用“交易信息待完善”占位，避免正文高度塌陷。

## 可访问性与交互

- 整张卡片继续作为详情入口，点击行为不变。
- 角标只提供状态信息，不增加独立点击行为。
- 角标文字必须保持足够对比度，不能只依靠颜色表达业务类型。
- 供需颜色是对类型文案的辅助编码，用户仍可通过“尾货批发”“求购尾货”等具体文字理解业务方向。

## 验证标准

### 结构与视觉

- 供需市场的供应和需求卡片均为“图片 + 三行正文”结构。
- 图片左上只展示具体业务类型，不再展示独立的“供应 / 需求”角标。
- 供应类型角标为深色，需求类型角标为橙色。
- “织里”等地区文本、品类摘要和资源标签不在供需市场卡片中出现。
- 标题、数量与价格、商户与更新时间分别占据稳定的一行。
- 已完成状态显示在图片右上，且不与业务类型角标重叠。
- 长标题、长价格、长类型和长商户名称均不会导致横向溢出或卡片增高。

### 作用范围

- `wxapp/pages/market/index.vue` 显式启用 `market` 变体。
- 搜索页、首页、收藏页、专题页和通用资源列表未传入 `market` 变体，继续保持现有布局。
- 卡片点击、曝光统计、列表分页和详情跳转保持不变。
