# 供需列表已完成水印设计

## 目标

让首页近期供需与供需市场列表中的已完成资源更容易被识别，同时保持标题、交易信息和商家信息可读。

## 方案

仅调整共用组件 `wxapp/components/ResourceFeedCard.vue`：

- 已完成资源继续保留封面右上角的“已完成”角标，提供明确、紧凑的状态说明。
- 在整张卡片内新增“已完成”斜向水印，位于内容层之下，以低透明度显示。
- 卡片内容维持在水印之上；水印不参与点击、不影响卡片原有打开行为。
- 未完成资源不渲染水印，现有供给与需求的类型标识、布局和数据逻辑保持不变。

## 样式边界

- 水印使用较大的粗体字和低对比度灰蓝色，采用轻微旋转，强化状态但避免喧宾夺主。
- 通过绝对定位和 `pointer-events: none` 保证水印覆盖全卡片范围，并且不会拦截点击。
- 不新增接口、数据字段或组件参数。

## 验收标准

1. `dealtAt` 有值时，市场页和首页的供需列表卡片均显示右上角角标和整卡水印。
2. `dealtAt` 无值时不显示水印。
3. 标题、交易信息、商家与更新时间仍正常展示，点击卡片仍可打开详情。
4. 现有组件源码断言和小程序构建通过。
