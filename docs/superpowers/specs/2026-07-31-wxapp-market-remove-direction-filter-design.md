# 供需页面移除方向筛选设计

## 背景

供需首页和搜索页当前都在搜索框和类目筛选之间展示“全部 / 供应 / 需求”方向筛选栏。该筛选增加了操作层级，也压缩了内容展示空间。

## 目标

- 移除供需首页的“全部 / 供应 / 需求”筛选栏。
- 移除供需搜索页的“全部 / 供应 / 需求”筛选栏。
- 供需首页始终展示供应和需求组成的混合信息流。
- 搜索页始终返回供应和需求组成的混合搜索结果。
- 保留关键词、类目、标签、类目抽屉、下拉刷新和分页加载能力。

## 实现范围

修改 `wxapp/pages/market/index.vue`：

- 删除方向筛选栏模板和样式。
- 删除 `directionFilterOptions` 和 `chooseResourceDirection`。
- 删除首页筛选状态中的 `direction`。
- 首页请求不再传递 `direction`，由后端按照默认规则返回供需混合列表。
- 类目列表不再按方向二次过滤。
- 从供需首页进入搜索页时不再传递方向条件。

修改 `wxapp/pages/search/index.vue`：

- 删除方向筛选栏模板和样式。
- 删除 `directionFilterOptions`、`chooseResourceDirection` 和方向值标准化逻辑。
- 删除搜索筛选状态中的 `direction`。
- 路由参数和首页传入的待搜索条件不再读取方向条件。
- 搜索请求不再传递 `direction`，类目列表不再按方向二次过滤。

同步调整供需首页、搜索页的页面测试和流程校验，明确两个页面都采用供需混合流。

## 数据与异常处理

本次不修改接口协议或后端逻辑。列表和搜索请求仍使用现有接口，省略方向参数后使用服务端默认的混合查询行为。现有加载、空态、刷新和分页错误处理保持不变。

## 验收标准

1. 供需首页不再出现“全部 / 供应 / 需求”筛选栏。
2. 供需首页请求不携带 `direction`。
3. 供应卡片和需求卡片仍能在同一列表正常展示。
4. 类目筛选、搜索入口、下拉刷新和上拉分页正常工作。
5. 搜索页不再出现“全部 / 供应 / 需求”筛选栏，搜索请求不携带 `direction`。
6. 搜索页关键词、类目、标签和分页能力正常工作。
7. 小程序自动化检查和构建通过。
