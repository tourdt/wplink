# 供需详情无图隐藏图片区块设计

## 目标

供需详情没有图片时，不再展示“暂无图片”占位区域。用户进入详情后直接看到自动摘要，减少首屏空白和无效提示，让关键供需条件更早进入视线。

## 范围

### 包含

1. 仅当详情存在图片时渲染图片区块与轮播交互。
2. 无图时自动摘要卡成为详情正文的首个区块。
3. 删除详情页中仅服务于无图占位的状态、模板和样式。
4. 更新详情页回归测试，覆盖有图保留图库、无图隐藏图库两种场景。

### 不包含

1. 不改变图片上传、编辑、预览和发布流程。
2. 不增加任何接口或后端字段。
3. 不改变自动摘要、商家资料入口、联系方式和管理操作规则。

## 实现设计

- 将 `detail-gallery` 外层改为以 `galleryImages.length` 为条件渲染；有一张或多张图片时，保留现有单图/轮播和全屏预览行为。
- 当图片为空时，跳过整个图库，不渲染无图封面，也不展示详情页内的“补充图片”按钮；发布者仍可从“我的发布”进入编辑页补图。
- 删除 `noImageBadgeText`、`noImageStateTitle`、`noImageHintText`、`canEditOwnResourceWithoutImage` 等无图占位专用计算状态，以及对应 CSS。
- 自动摘要继续紧接在图库之后；图库不存在时自然位于内容顶部，无需新增间距补偿。

## 验收标准

1. 无图详情页源码不再包含无图占位模板和相关样式。
2. 有图详情继续支持单图展示、多图轮播及预览。
3. 无图详情的首个业务信息为自动摘要卡。
4. 详情页其余数据展示与交互不受影响。
