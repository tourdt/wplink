# 供需列表已完成印章水印设计

## 目标

将当前供需列表的普通大字水印改为更有完成凭证感的浅色印章，同时减少重复状态提示，使首页和供需市场的已完成资源更易识别且不影响内容阅读。

## 方案

仅调整共用组件 `wxapp/components/ResourceFeedCard.vue`：

- 已完成资源在卡片内容区展示浅灰蓝色的印章水印，位置沿用原水印的卡片中部偏右区域。
- 印章由圆形底纹、少量星形装饰和斜向矩形“已完成”章面组成；颜色低对比度、透明度较低。
- 删除封面右上角的 `feed-completed-badge` 及关联的类型标签宽度收窄逻辑，避免同一状态重复出现。
- 未完成资源不渲染印章；供需类型角标、数据模型、点击事件和页面调用方式保持不变。

## 样式边界

- 印章作为绝对定位的纯展示层，使用 `pointer-events: none`，不得阻断卡片点击。
- 封面和文字信息位于印章之上，保证标题、交易信息、商家与更新时间的可读性。
- 不使用图片资源或新增接口，印章完全由组件模板和 SCSS 绘制。

## 验收标准

1. `dealtAt` 有值时，首页与供需市场列表卡片显示浅色圆章和斜向“已完成”章面。
2. 封面右上角不再显示“已完成”文字，类型角标可使用完整可用宽度。
3. `dealtAt` 无值时不显示任何印章。
4. 卡片内容可读、点击仍可打开详情，组件测试和小程序完整检查通过。
