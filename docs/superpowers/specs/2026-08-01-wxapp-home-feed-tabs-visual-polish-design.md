# 小程序首页内容标签轻量化设计

日期：2026-08-01

## 1. 背景与目标

首页“新入驻商家 / 近期供需”当前采用等宽分段按钮：外层灰色底、描边、圆角，选中项再叠加白色背景和阴影。控件视觉重量偏高，与下方紧凑列表的内容节奏不一致。

本次仅优化双标签的视觉和交互反馈，使其更像首页内容栏目导航。现有数据加载、默认标签、内容降级、跳转和接口行为保持不变。

## 2. 已确认方案

采用“左对齐栏目”样式：

```text
新入驻商家    近期供需
━━━━━━
当前栏目对应的内容列表
```

- 两个标签按文字宽度左对齐排列，不再等宽撑满容器；
- 标签之间使用固定间距，形成自然的栏目分组；
- 标签区底部保留一条浅色分隔线，衔接下方内容；
- 当前标签使用主色文字，并在文字下方显示同宽细线；
- 未选中标签使用弱化文字色；
- 移除外层灰色底、描边、圆角块和阴影。

## 3. 尺寸与交互

- 每个标签继续保留至少 `88rpx` 的点击高度，不因轻量化缩小触控区域；
- 两个标签之间的视觉间距为 `36rpx`；
- 选中线为 `4rpx` 高，宽度跟随标签文字，不横向填满半屏；
- 切换时只更新本地 `activeHomeFeedTab`，不增加动画、不重新请求接口；
- 按钮按下态使用轻微透明度变化，避免缩放或位移动效造成列表抖动；
- 不修改标签文案，继续使用“新入驻商家”和“近期供需”。

## 4. 状态与降级

- 两类内容都有数据时显示轻量双标签；
- 只有一类内容可用时，继续隐藏切换控件并展示现有单栏目标题；
- 有新商家时默认选中“新入驻商家”，否则展示“近期供需”；
- 两类内容均为空时继续隐藏整个内容区；
- 接口失败和公开资源兜底逻辑保持现状；
- 切换后的列表渲染继续使用 `v-if / v-else`，不改变组件生命周期规则。

## 5. 实现边界

改动集中在 `wxapp/pages/home/index.vue`：

1. 标签容器使用 `role="tablist"`，两个标签按钮使用 `role="tab"` 和动态 `aria-selected`，明确当前选中状态；
2. 将 `.home-feed-tabs` 从等宽分段容器调整为左对齐栏目导航；
3. 将 `.home-feed-tab` 的选中态改为文字颜色加底部细线；
4. 保留现有最小点击高度和按钮伪元素清理规则。

不新增组件，不修改 `homeFeedState`，不调整商家卡片或供需卡片样式。

## 6. 测试与验收

### 6.1 自动化验证

1. 首页模板仍包含两个标签及原有切换事件；
2. 标签按钮具备选中状态语义；
3. `.home-feed-tab` 继续保留 `min-height: 88rpx`；
4. 标签容器不再使用等宽两列网格、灰色背景、外描边和圆角分段底；
5. 选中标签通过文字色和底部细线表达状态；
6. 运行首页定向测试和微信小程序构建。

### 6.2 视觉验收

1. 两个标签在常见手机宽度下保持单行，不重叠、不截断；
2. 当前标签与未选中标签的状态清晰可辨；
3. 标签区与首张列表卡片之间的留白自然；
4. 点击区域足够，切换时页面不发生横向位移或明显抖动；
5. 只有一类内容时，单栏目标题样式保持正常。

## 7. 不在本次范围

- 不修改首页接口、排序、数量和兜底策略；
- 不调整商家与供需列表卡片；
- 不增加数量徽标、图标、滑动手势或切换动画；
- 不改造其他页面的标签控件；
- 不调整首页其余区块的间距和视觉样式。
