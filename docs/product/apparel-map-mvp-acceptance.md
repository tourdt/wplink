# 织里服装地图首发验收清单

版本：v1.0  
日期：2026-10-09  
性质：待实施目标验收，不表示当前代码已经通过  
关联需求：[织里服装地图产品需求文档](apparel-map-mvp-prd.md)

## 1 导航与首发范围

- [ ] 打开小程序默认进入找档口，底部为找档口和我的。
- [ ] 不显示发布、供需市场、VIP、付费权益或空商品栏目。
- [ ] 游客可以搜索、浏览店铺和导航；拒绝当前位置授权仍可使用列表。
- [ ] 登录后返回原入驻操作，草稿内容不丢失；登录本身不使商家公开入驻。
- [ ] 旧资源页面、分享链接和直接接口调用遵循暂未开放规则，不能绕过入口限制发布或购买相关权益。

## 2 从零入驻

- [ ] 在没有预录地图点位的环境，新商家仍可填写资料、选点和提交。
- [ ] 草稿可保存，不进入公开列表；缺少主营、实拍、地址或有效位置时不能提交成功。
- [ ] 无独立 Logo 不阻止入驻；可用店铺实拍作封面。
- [ ] 分类编码无效、位置超出服务范围或坐标非法时，服务端拒绝并显示明确原因。
- [ ] 校验通过后商家在列表和筛选结果中出现，点开为同一商家主页。
- [ ] 重复点击提交或请求重试不产生重复店铺或点位。
- [ ] 异常内容处理中或需修改时显示真实状态；未完成校验的资料不提前公开。
- [ ] 无需发布资源、购买会员或获得发布额度即可完成入驻。

## 3 查找与主页

- [ ] 店名、主营、市场及已填写的档口地址信息可被搜索。
- [ ] 主营多选为任一匹配，关键词和分类同时生效；提交的主营能被对应筛选找到。
- [ ] 分页稳定，切换条件重置结果；零结果和网络失败有不同提示。
- [ ] 主页展示有效店名、主营、简介、图片和详细地址，不要求有已发布资源。
- [ ] 分享后进入同一店铺；暂停、隐藏和停用店铺的旧链接不返回其公开业务资料。
- [ ] 空库能正常打开，显示首批入驻引导，无演示商家和伪造数量。

## 4 位置与导航

- [ ] 商家选点和详细地址可以核对，市场内店铺能补充楼层与档口号。
- [ ] 导航目标与主页位置一致，已验证坐标来源与第三方地图的坐标系处理。
- [ ] 手工修改地址或清除位置后旧导航立即失效，店铺退出目录直至新位置生效。
- [ ] 位置服务或导航调起失败时可重试、复制地址，不影响页面其他内容。
- [ ] 用户不授权当前位置仍能导航到店铺位置；如第三方能力另需授权，失败提示可理解且可退出。
- [ ] 若保留附近商家，其失败不影响当前商家导航。
- [ ] 登录用户可提交位置报告；报告不会直接覆盖坐标，后台处理有原因和记录。
- [ ] 商家普通资料保存不能解除平台人工隐藏，未配置的报告计数不得意外触发处罚。

## 5 联系与经营状态

- [ ] 默认不公开业务联系方式，不自动公开登录手机号。
- [ ] 分别选择公开电话、微信后，只有获准字段返回给访客；关闭选择后立即不再返回。
- [ ] 未公开联系方式不影响浏览和导航。
- [ ] 其他用户不能编辑、暂停、恢复该店铺或读取私有联系人字段。
- [ ] 商家暂停后退出目录，恢复时重新校验完整性与平台限制。
- [ ] 后台可以检索、处理异常、隐藏和恢复，操作记录能追溯对象、操作人和原因。

## 6 后续扩展保护

- [ ] 原商家 ID、用户归属与有效主页入口保留，不因首发改版重新注册商家。
- [ ] 现有资源数据和所属商家关系保留，停用模块不执行破坏性清库。
- [ ] 店铺与资源公开状态分别判断，地图不依赖资源数量、审核或付费状态。
- [ ] 未开放资源业务不向首发用户发送不适用的推广、权益和发布提醒。
- [ ] 后续可通过同一商家标识查询其资源，主页无需另建身份或迁移商家数据。

## 7 指标与验收证据

- [ ] 能区分入驻开始、入驻公开、主页访问、导航意向、联系动作和位置报告。
- [ ] 页面重试和重复提交不明显重复统计同一业务成功事件。
- [ ] 统计不把地图调起成功当作真实到店，不把点击电话当作实际成交。
- [ ] 记录验收环境、版本、场景、预期、实际结果和待解决问题。
- [ ] 按改动范围运行已有小程序检查、后端模块测试及接口生成一致性检查；涉及迁移时验证迁移与历史数据兼容。
- [ ] 在微信开发者工具或真机，以及可用后端、数据库、图片和位置服务环境中完成核心闭环，不以静态检查代替端到端验收。

具体命令由实施改动确定。第二阶段资源发布需另行补充发布、审核、上下架、有效期、联系方式和权限场景，不自动将本清单扩为交易平台验收。
