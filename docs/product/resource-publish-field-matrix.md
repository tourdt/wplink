# 发布供需信息与发布需求字段矩阵

本文档用于产品评审小程序“发布供需信息”和“发布需求”的字段设计。目标是让不同类型的发布表单只展示符合业务语义的字段，避免所有类型都套用“品类、数量、价格”导致重复或误导。

## 字段分层说明

### 通用字段

所有“发布供需信息”和“发布需求”类型都保留以下通用字段：

| 字段 | 页面文案 | 建议要求 | 说明 |
| --- | --- | --- | --- |
| 发布类型 | 供需类型 / 需求类型 | 必填 | 用户选择本次发布属于哪一类。 |
| 标题 | 标题 | 必填 | 用于列表、详情和搜索结果主标题。 |
| 详细说明 | 供需信息描述 / 需求描述 | 建议填写 | 用于补充交易条件、要求、注意事项。 |
| 图片 | 供需信息图片 / 参考图片 | 建议填写 | 供应侧展示实物或场景，需求侧展示参考款或参考资料。 |
| 联系人 | 联系人 | 必填 | 供对方和平台审核联系。 |
| 联系电话 | 联系电话 | 必填 | 供对方和平台审核联系。 |

### 系统摘要字段

以下字段用于搜索、筛选、列表卡片和后台审核，不建议作为所有类型的固定输入框展示。系统应从各类型专属字段自动生成。

| 摘要字段 | 用途 | 示例来源 |
| --- | --- | --- |
| 分类摘要 | 替代旧的“品类”展示和筛选 | 库存品类、服务类型、房源类型、岗位、标的类型 |
| 数量摘要 | 替代旧的“数量/产能”展示 | 库存数量、日产能、人数、面积、需求数量 |
| 价格摘要 | 替代旧的“价格描述/预算描述”展示 | 打包价、供货价、工价、租金、预算范围 |

## 发布供需信息字段矩阵

### 库存清仓

通用字段：发布类型、标题、详细说明、图片、联系人、联系电话。

| 类型专属字段 | 建议要求 | 说明 |
| --- | --- | --- |
| 库存品类 | 必填 | 例如童装、女装、卫衣、套装。 |
| 季节 | 建议填写 | 春季、夏季、秋季、冬季。 |
| 尺码段 | 建议填写 | 例如 90-140、成人 S-XL。 |
| 库存数量 | 必填 | 例如 3200 件、80 包。 |
| 打包价/单件价 | 必填 | 例如打包 18 元/件。 |
| 支持拿样 | 建议填写 | 是否允许先拿样。 |
| 支持直播 | 建议填写 | 是否适合直播、电商带货。 |
| 仓库位置 | 建议填写 | 方便买家判断看货成本。 |

系统摘要：分类摘要=库存品类；数量摘要=库存数量；价格摘要=打包价/单件价。

### 现货货源

通用字段：发布类型、标题、详细说明、图片、联系人、联系电话。

| 类型专属字段 | 建议要求 | 说明 |
| --- | --- | --- |
| 货源品类 | 必填 | 例如童装、女装、面料、配饰。 |
| 风格 | 建议填写 | 韩版、学院风、运动风、国潮、基础款等。 |
| 供货价/价格带 | 必填 | 例如 18-25 元/件。 |
| 起批量 | 建议填写 | 例如 20 套起批。 |
| 是否现货 | 建议填写 | 是否可立即发货。 |
| 一件代发 | 建议填写 | 是否支持一件代发。 |
| 供货区域 | 建议填写 | 例如织里及周边、全国发货。 |

系统摘要：分类摘要=货源品类；数量摘要=起批量；价格摘要=供货价/价格带。

### 工厂接单

通用字段：发布类型、标题、详细说明、图片、联系人、联系电话。

| 类型专属字段 | 建议要求 | 说明 |
| --- | --- | --- |
| 擅长品类 | 必填 | 例如童装、女装、羽绒服、针织。 |
| 日产能 | 必填 | 例如 1200 件/天。 |
| 起订量 | 建议填写 | 例如 300 件起。 |
| 接小单 | 建议填写 | 是否承接小单快反。 |
| 当前空档期 | 建议填写 | 本周可排单、下周可排单、本月可排单等。 |
| 工价范围 | 建议填写 | 例如按款报价、计件区间。 |
| 加工方式 | 建议填写 | 包工包料、来料加工、清加工等。 |

系统摘要：分类摘要=擅长品类；数量摘要=日产能；价格摘要=工价范围。

### 招工招聘

通用字段：发布类型、标题、详细说明、图片、联系人、联系电话。

| 类型专属字段 | 建议要求 | 说明 |
| --- | --- | --- |
| 岗位 | 必填 | 平车工、拷边工、裁剪工、后道、包装工等。 |
| 工价/薪资 | 必填 | 例如计件 0.8-1.2 元、月薪区间。 |
| 人数 | 必填 | 例如招 8 人。 |
| 包吃住 | 建议填写 | 是否提供吃住。 |
| 工作地点 | 必填 | 例如织里某园区、某市场附近。 |
| 结算方式 | 建议填写 | 计件、日结、月结等。 |
| 班次/工作时长 | 建议填写 | 白班、晚班、长白班等。 |

系统摘要：分类摘要=岗位；数量摘要=人数；价格摘要=工价/薪资。

### 出租转让

通用字段：发布类型、标题、详细说明、图片、联系人、联系电话。

| 类型专属字段 | 建议要求 | 说明 |
| --- | --- | --- |
| 房源类型 | 必填 | 厂房、档口、仓库、商铺、商品房、宿舍、设备等。 |
| 面积 | 必填 | 例如 120 平。 |
| 租金 | 必填 | 例如 6800 元/月。 |
| 位置 | 必填 | 例如童装城附近、某园区。 |
| 楼层 | 建议填写 | 例如 1 楼、2 楼。 |
| 转让费 | 建议填写 | 例如无、面议、具体金额。 |
| 租期条件 | 建议填写 | 押金、租期、可入驻时间等。 |

系统摘要：分类摘要=房源类型；数量摘要=面积；价格摘要=租金。

### 配套服务

通用字段：发布类型、标题、详细说明、图片、联系人、联系电话。

| 类型专属字段 | 建议要求 | 说明 |
| --- | --- | --- |
| 服务类型 | 必填 | 物流、辅料、印花、绣花、摄影、直播、包装等。 |
| 服务范围 | 必填 | 例如织里及周边、全国接单。 |
| 价格方式 | 建议填写 | 例如按单报价、按件计费、面议。 |
| 响应时效 | 建议填写 | 例如当天出样、24 小时响应。 |
| 服务案例 | 建议填写 | 是否有案例、可展示案例类型。 |
| 可服务区域 | 建议填写 | 城市、商圈、产业带范围。 |

系统摘要：分类摘要=服务类型；数量摘要=服务范围；价格摘要=价格方式。

## 产品确认点

1. 通用字段是否保持为“类型、标题、详细说明、图片、联系人、联系电话”。
2. 每个类型的必填字段是否符合业务优先级。
3. `分类摘要` 是否用于替代原来的“品类”概念。
4. `数量摘要` 和 `价格摘要` 是否允许为空；为空时卡片不展示对应占位文案。
5. “找服务、配套服务”是否需要补充更细的服务类型选项。
6. “找场地、出租转让”是否需要把“设备”从房源类里拆成独立类型。
