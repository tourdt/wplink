# 微信小程序手工验收

本文档中依赖微信开发者工具、真机定位、腾讯地图和三个独立微信账号的项目，在纯终端环境的验收状态统一标记为：**待人工真机验收**。

## 前置条件

- 后端生产或验收环境 `/healthz`、`/readyz` 均返回 `ok`。
- 微信公众平台已配置 request、uploadFile、downloadFile 合法域名。
- `wxapp/dist/mp-weixin` 已用生产 API 域名构建。
- 微信开发者工具已导入项目，AppID 使用正式或体验版 AppID。
- 准备一个可编辑商家的账号、三个不同的已登录报告账号，以及至少两家在 1000 米内的织里测试商家。

## 织里商家目录与位置治理八步验收

1. 不选位置保存与发布
   - 清除商家已选位置，保存商家资料，再创建并提交一条供需信息。
   - 预期：资料保存成功，供需信息可正常发布和管理；商家不出现在拿货档口。无有效坐标时，商家主页仍可显示和复制文字地址，但不显示查看位置或导航入口。

2. 选择织里腾讯地图位置
   - 在商家资料页调用选择位置，选中织里的真实位置，填写市场、楼栋、楼层和档口号并保存。
   - 预期：定位名称、经纬度和结构化档口资料正确回显，位置状态为 `visible`；不展示任何额外公开开关或审核中状态。

3. 验证无审核入目录
   - 保存后直接进入“拿货档口”并刷新，不在后台执行任何审核操作。
   - 预期：列表立即出现该商家，卡片只展示公开安全字段，可进入商家主页和查看位置。

4. 验证目录搜索
   - 分别用完整商家名、市场名和档口号搜索，并切换主营品类筛选。
   - 预期：三种关键词都能命中该商家，品类筛选、翻页、刷新和空态正常，页面不请求用户实时位置。

5. 验证商家位置页和附近商家
   - 从目录打开该商家位置页，点击附近商家 Marker 和列表项。
   - 预期：微信原生地图显示当前商家与 1000 米内最多 20 家附近商家，Marker、底部详情和附近商家列表联动正确。

6. 验证腾讯位置导航
   - 点击当前商家的“导航”，在腾讯位置页核对名称和坐标，然后返回小程序。
   - 预期：`uni.openLocation` 正常打开，目标名称和位置与商家保存值一致，返回后页面状态正常。

7. 验证三个不同用户自动隐藏
   - 用三个不同登录账号依次报告同一商家位置错误，每次后刷新目录和商家主页。
   - 预期：前两次报告成功且位置仍可见；第三个不同用户报告后状态自动变为 `risk_hidden`，商家立即退出目录，位置与导航入口不再公开。

8. 验证重新选点恢复与后台结案
   - 商家回到资料页重新选择有效位置并保存；后台进入“商家管理”，查询该商家的位置状态和报告。
   - 预期：商家恢复 `visible` 并重新进入目录，历史 `pending` 报告已结案且审计记录保留；后台可继续查看报告，并可在商家管理内人工隐藏或恢复位置。

## 其他 MVP 验收流程

1. 登录与商家身份
   - 打开“我的”页。
   - 完成微信登录。
   - 若账号未绑定商家，先完成商家资料入驻。
   - 预期：页面展示商家资料和权益余量。

2. 发布、审核、搜索、联系、指标
   - 在“发布”页填写供需信息标题、品类、数量、价格、联系人和电话。
   - 提交后进入发布成功页。
   - 后台 `/admin/resources/pending` 审核通过该供需信息。
   - 小程序“搜索”页输入关键词，进入供需信息详情。
   - 点击电话、复制微信、商家主页入口。
   - 回到“我的发布”。
   - 预期：供需信息状态为已发布，详情浏览、电话、微信指标增加。

3. 搜索无结果空态
   - 搜索一个不存在的关键词。
   - 查看搜索无结果空态。
   - 尝试更换关键词、切换筛选条件或点击热门搜索词。
   - 预期：页面不展示“提交需求”和“我的需求”入口，可继续搜索已有供需信息。

4. 商家资料和权益
   - 进入商家资料页，修改名称、头像、展示图片或联系方式。
   - 保存后回到商家主页和“我的”页。
   - 查看商家权益与置顶券余量。
   - 预期：资料更新正确，权益余量与后台发放记录一致。

5. 我的发布管理
   - 在“我的发布”按状态筛选。
   - 对已发布供需信息执行刷新、置顶、标记成交、下架。
   - 对已过期或已成交供需信息执行“再发类似”。
   - 预期：状态流转正确，草稿可再次提交审核。

6. 消息中心
   - 触发供需信息审核通过、驳回或过期消息。
   - 进入消息中心，切换全部、未读、已读。
   - 点击未读消息。
   - 预期：消息可读，已读状态更新。

7. Banner、专题和 web-view
   - 后台新增或启用 Banner。
   - 小程序首页点击 Banner。
   - 分别验证跳转专题、供需信息详情、商家主页和白名单 web-view。
   - 预期：白名单链接可打开，非白名单链接显示不可访问。

8. 图片比例和裁切
   - 首页 Banner、专题 Banner 使用统一横图比例。
   - 首页活动卡、供需信息列表缩略图、同类推荐缩略图使用方图。
   - 供需信息详情主图使用 4:3，详情小图使用方图。
   - web-view 活动页封面使用 16:9。
   - 预期：图片使用中心裁切，不出现卡片高度跳动、图片挤压变形或页面横向滚动。

## 通过标准

- 以上核心流程全部通过。
- 所有 `app.api` 契约内接口均进入真实 Handler；未声明 API 返回 404，错误 HTTP method 返回 405。
- 无页面停留在永久 loading。
- 用户可见错误为中文且可操作。
- 图片上传、微信登录均使用真实生产服务；短信验证码和手机号绑定不纳入首发验收。
